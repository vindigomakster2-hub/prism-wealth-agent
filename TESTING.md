# Как протестировать всю систему Halo

Инструкция идёт от простого к сложному. Блоки 0–2 обязательны: установка, автотесты и главный сценарий. Остальное можно проверять выборочно.

---

## 0. Подготовка

**Нужно:** Node.js 20 или новее (проверено на 25), npm, свободные порты 8545, 8787 и 5173.

```bash
npm install
npm run dev
```

`npm run dev` компилирует контракты и поднимает три процесса:

| Процесс | Адрес | Что делает |
|---|---|---|
| `chain` | 127.0.0.1:8545 | Локальный блокчейн Hardhat (только тестовые ключи) |
| `server` | 127.0.0.1:8787 | Агент. При первом запуске деплоит контракты и заполняет демо-данные |
| `web` | **http://127.0.0.1:5173** | Интерфейс |

**Как понять, что всё готово:** в логе сервера есть строки `world deployed` (или `world reused`) и `autopilot every 4000 ms`, а приложение открывается на карте капитала.

> Предупреждение Hardhat про версию Node.js безвредно, его можно игнорировать.

## 1. Автотесты (≈1 минута)

Во **втором** терминале, пока работает `npm run dev`:

```bash
npm run test:e2e
```

**Ожидаемый результат:** `78/78 passed`. В конце тест сам сбрасывает мир в стартовое состояние.

Что проверяют 14 разделов:

| № | Раздел | Что проверяется |
|---|---|---|
| 1 | Движки | Net worth = активы − долги; аллокация = 100%; риск-находки; кредитный скор Tier 2 (≈785); капитал по риску и по «поведению»; алерты |
| 2 | Proof of Wealth | Аттестация на блокчейне, ставка 9% → 6%, кредитная линия ≤ 50% залога, займ сверх стандартного лимита |
| 3 | Мандат | Лимит займа, лимит переводов в день, неизвестный получатель, проскальзывание, запрещённые действия, резерв кэша |
| 4 | Автономность | L1 ждёт одобрения, L2 сам выполняет защитные действия, L3 выполняет всё; валидация ввода |
| 5 | **Атаки на контракт напрямую** | Ключ агента, минуя сервер: перевод чужому, approve чужому, вызов вне allow-list, дневной лимит, порог здоровья кредита, чужой ключ, kill switch |
| 6 | CreditRegistry | Поддельная подпись, повтор подписи, просроченная аттестация, двойной залог в два пула |
| 7 | Обвал ETH | «Пассивный близнец» ликвидирован, кошелёк агента нет |
| 8 | +31 день | Агент обновляет доказательство, а не гасит долг кэшем |
| 9 | Страховка | Ликвидация в режиме L0 → автоматическая выплата по полису |
| 10 | Prompt injection | Три попытки, три блокировки (политика → контракт → контракт), деньги не ушли |
| 11 | Источники и чат | Отключение банков лишает права на кредит; офлайн-чат отвечает |
| 12 | Cash flow | Автосинк, обучение по ответу, CSV T-Bank/Fio/Sber/DEGIRO, дедупликация, чек «научил → узнал», бюджеты в %, ипотека → истинный баланс < 0, недвижимость, частный долг, Telegram, удаление данных |
| 13 | Экспозиция и стресс-тест | Секторы и регионы с разбором фондов (look-through) дают ровно 100% активов; свои параметры стресса: одна позиция, сектор через фонды, ставки +200 б.п. (облигации по дюрации, плавающий долг), потеря дохода → запас в месяцах, валютный шок переоценивает долг в EUR; некорректный ввод обрезается; сохранение сценариев; профиль меняет emergency fund, возраст 3 → 400; настройки сохраняются; провайдер ИИ = Groq |
| 14 | Безопасность | JSON-бэкап с аудитом, запрос с чужого сайта → 403, подмена Host → 421 |

Если тест упал, под ним напечатана причина. Чаще всего сервер ещё не поднялся: подождите 10–20 секунд и перезапустите.

## 2. Главный сценарий для жюри (5–7 минут)

Перед показом сбросьте мир: **Demo lab → Reset the world**.

### 2.1 Карта капитала (первая вкладка)
1. Слева светится шар **Net worth ≈ $320,170**. В середине карточки категорий: депозиты, акции, облигации, венчур, крипто, долги, страховки. Справа веер отдельных позиций в разных банках, у брокера и в кошельке.
2. Кликните **Stocks & ETFs**. Карточка подсвечивается, её линии становятся яркими, остальные гаснут. Рядом открывается **краткая справка**: сумма, доля в активах, крупнейшие позиции и находки ИИ. Справа панель с KPI и AI-анализом («≈42% активов зависит от tech-цикла», с учётом состава фондов).
3. В справке нажмите **Dive deeper**: откроется подробный разбор категории — таблица позиций (доля, риск, срок до денег, доходность, залог), структура риска и чувствительность к шокам. Для отдельной позиции (например **NVIDIA**) там же слайдер «что если», график и быстрые действия. Для шара — полный баланс и лестница ликвидности.
4. **Перетащите** любую карточку или позицию мышью: раскладка меняется и запоминается после перезагрузки. Кнопка **−** на карточке сворачивает её позиции (**+N** разворачивает). Кнопка с крестом-стрелками в тулбаре (подсказка «Put dragged nodes back») или **Settings → Reset layout** возвращает автоматическую раскладку. Ничего не должно наползать друг на друга при любом размере окна.
5. Кликните на шар: вернётся сводка всего портфеля. Число позиций в плашке над картой совпадает с числом в панели Net worth.
6. Нажмите **See true balance** под шаром: увидите, сколько денег реально доступно за неделю минус все долги.
7. Проверьте тулбар: граф ↔ дерево, зум +/−, фильтр (только on-chain / off-chain, скрыть категории), сортировка, экспорт (CSV позиций или полный JSON-бэкап). Поиск (лупа справа): «nvidia» + Enter выделит позицию.
8. **New simulation → 2008-style crash → Preview on the map.** На каждой позиции появится красная дельта, шар покажет итоговый % падения. Clear убирает симуляцию.
9. Внизу панели строка «Ask about your money…»: спросите «How risky am I?».

### 2.2 Proof of Wealth
1. Вкладка **Proof of Wealth → Publish proof.** Ставка падает 9% → **6%**, появляется кредитная линия **$8,500** (50% от залога).
2. Слайдер займа на $6,000 → **Borrow**. Займ проходит, хотя по стандартным условиям столько не дали бы.

### 2.3 Страховка
**Earn & Protect → Buy cover** ($1,500 на 90 дней, премия около $15).

### 2.4 Demo lab: самое зрелищное
1. **Run ETH sell-off (−35%)**: цена падает в 5 шагов. Близнец справа **Liquidated**, ваш кошелёк **Safe**, потому что агент сам добавил ETH в залог. В Market tape видно хронологию.
2. **Restore price.**
3. **Launch attack** (prompt injection из банковской выписки): три попытки и три блокировки. Раскройте карточки: видно, на каком слое остановлено (Policy → On-chain → On-chain).
4. **+31 days**: доказательство истекло, автопилот переиздал его до того, как тратить кэш.

### 2.5 Агент
1. Вкладка **Agent → L1 Ask first.** В чате напишите `Repay 500`: появится карточка в Approvals → **Approve and execute**.
2. **Pause agent key**: ключ агента заморожен на блокчейне. Любое действие теперь блокируется. Нажмите **Resume**.
3. Audit trail: у каждого действия есть причина, заявленное намерение, симуляция, все проверки и хеш транзакции.

## 3. Cash flow (новая вкладка, иконка чека)

### 3.1 Вопросы агента и обучение
1. В карточке **Agent questions** висят непонятные переводы «ZELLE TO A. SMIRNOV».
2. Нажмите **Repaying a private loan** у любого. Тост: «…updated 2 similar». Все такие переводы закрыты, и агент запомнил этого получателя.
3. Каждые 15 секунд работает **автосинхронизация с банком** (кнопка Auto-sync on/off, или **Sync now**). Приходят новые транзакции; «TST* OSTERIA ROMA» агент не знает и спрашивает. Ответьте «Café / restaurant». Когда эта же транзакция придёт снова, она сама получит статус **Learned**.
4. Справа карточка **Telegram**: те же вопросы в виде переписки с ботом, кнопки работают и отсюда. Статус «Linked» / «Not linked»; инструкция по подключению бота — в README, раздел «Telegram bot».

### 3.2 Импорт выписок
Карточка **Import a statement**, кнопки-примеры:
- **T-Bank**: распознаётся профиль «T-Bank (Тинькофф)». Строка FAILED пропускается, рубли пересчитываются в $, «Пятёрочка» → Groceries, «ИП Смирнов» и «Перевод по СБП» уходят в вопросы. **Import 13.** Повторный импорт того же файла даёт 0 новых: работает дедупликация.
- **Fio (CZ)**: кроны, Albert → Groceries, Alza → вопрос.
- **Sber**: распознаётся профиль Sber.
- **DEGIRO positions**: позиции брокера становятся отдельным счётом на карте. Он помечен как self-reported и **не учитывается** в Proof of Wealth.
- Можно загрузить свой CSV (**Choose CSV**). Если колонки не распознались, их можно выбрать вручную. Файлы в Windows-1251 (частый случай у российских банков) читаются автоматически.

### 3.3 Сканер чеков
1. **Sample receipt 1** (Лента): 9 позиций с сокращениями («МОЛ ПАСТ…», «З/П COLGATE»). Часть категорий подставлена правилами, у неизвестных стоит «Teach me…». Выберите категории → **Save receipt**.
2. **Sample receipt 2 (a week later)**: значок «**N of 8 recognised from memory**». То, чему научили в первый раз, теперь распознаётся само.
3. **Photo** работает с реальной фотографией чека, если заданы `GROQ_API_KEY` и `GROQ_VISION_MODEL` (модель Groq, которая принимает изображения).

### 3.4 Бюджеты, долги, истинный баланс
1. **Budgets**: добавьте «Repaying private loans, 3% of income» (пример из отзывов). Видно потраченное, лимит и статус (зелёный, жёлтый или красный «over»).
2. **Debts → пресет Mortgage → Add debt.** **True balance** уходит в минус и подсвечивается красным, net worth на карте падает на $280k. План погашения отсортирован по ставке (лавина) и показывает срок до закрытия.
3. **What the agent noticed**: «Regular transfers to A. SMIRNOV look like a private loan». Введите остаток долга → **Track as a debt**. Долг появляется на карте в категории Debts, подсказка исчезает.
4. **Assets no API covers**: добавьте «Flat in Prague, 8 000 000 CZK». На карте появится категория **Real assets & other**.
5. **Safe to spend** (первая плитка) пересчитывается от дохода, обязательных платежей, 10% сбережений и уже потраченного.
6. **Delete all my data** (теперь в **Account**) — GDPR-удаление: отзывает все подключения и стирает офчейн-данные. Восстановление: **Demo lab → Reset**.

## 3a. Risk radar: экспозиция и свой стресс-тест

1. **Sector exposure**: ETF разложены по составу индекса (QQQ → Nasdaq-100, MSCI World → свои веса), поэтому сумма секторов и регионов ровно 100% активов. Под графиком видно, какие фонды разобраны.
2. **Concentration**: эффективное число позиций (1/HHI), доля топ-5, топ позиций и покрытие депозитов гарантией.
3. **Stress test**: выберите пресет (Tech correction, Crypto winter, 2008, Rates +200 bps, Job loss, Euro slide) или соберите свой: внизу блока «Your own parameters» выберите тип (группа, сектор, регион, валюта, учреждение, конкретная позиция) → цель → % шока → **Add**. Отдельно ползунки ставок (б.п.) и дохода (%).
   - Пример: NVIDIA −50%, сектор Technology −20%, ставки +200 б.п. → NVIDIA $26,100 → $10,440; QQQ теряет только технологическую часть (≈−10%); TLT −32% по дюрации; плавающий долг дорожает.
   - Income −100% (Job loss) показывает, на сколько месяцев хватит ликвидных денег.
4. Поле **Save as scenario…** → **Save** сохраняет свой сценарий; он появится среди пресетов и в **New simulation** на карте.

## 3b. Account и Settings (внизу левой панели)

1. **Account** (или клик по аватару): измените **Monthly expenses** с 3,400 на 6,800 → **Save profile**. Тост «recalculated», в тексте под формой запас наличных уменьшится вдвое. Возраст 3 → ошибка валидации. Здесь же ключи кошелька с паузой агента, JSON-бэкап и удаление данных.
2. **Settings**: переключатели Telegram (вопросы и алерты отдельно), автосинк банка, вид карты по умолчанию, сброс раскладки карты и статус интеграций (Groq, vision, Telegram, GoCardless).

## 4. Проверка через API (PowerShell)

```powershell
Invoke-RestMethod http://127.0.0.1:8787/api/health
(Invoke-RestMethod http://127.0.0.1:8787/api/state).risk.totals
(Invoke-RestMethod http://127.0.0.1:8787/api/cash).month.safeToSpend
Invoke-RestMethod -Method Post http://127.0.0.1:8787/api/demo/inject | Select-Object title, status, blockedBy
```

Атака с «чужого сайта» должна вернуть **403**:

```powershell
try { Invoke-RestMethod -Method Post http://127.0.0.1:8787/api/actions -ContentType 'application/json' -Headers @{ Origin = 'https://evil.example' } -Body '{"action":{"kind":"borrow","amountUsd":100}}' } catch { $_.Exception.Response.StatusCode }
```

Полный бэкап с аудит-логом: откройте http://127.0.0.1:8787/api/export (скачается JSON).

## 5. Реальные интеграции (по желанию)

Скопируйте `.env.example` в `.env` в корне репозитория, впишите ключи и перезапустите `npm run dev`. Переменные из оболочки (`$env:GROQ_API_KEY = "gsk_..."` в PowerShell) имеют приоритет. Что подключено, видно в **Settings → Integrations**.

| Интеграция | Что сделать | Как проверить |
|---|---|---|
| **ИИ (Groq)** | `GROQ_API_KEY` (ключ на console.groq.com), по желанию `GROQ_MODEL` (по умолчанию `openai/gpt-oss-120b`) и `GROQ_VISION_MODEL` | В шапке вместо «Offline agent» появится модель Groq. Чат отвечает свободно и вызывает инструменты; непонятные транзакции сначала разбирает ИИ; с vision-моделью распознаётся фото чека |
| **Telegram** | Пошагово в README, раздел «Telegram bot»: бот у @BotFather → `TELEGRAM_BOT_TOKEN` → перезапуск → `/start` боту | Карточка Telegram показывает «Linked». Новые непонятные транзакции приходят в чат с кнопками; ответ из Telegram сразу появляется в приложении. Отвечать может только привязанный чат |
| **Реальный банк (PSD2)** | Ключи GoCardless Bank Account Data: `GOCARDLESS_SECRET_ID`, `GOCARDLESS_SECRET_KEY` | `GET /api/connect/gocardless/institutions?country=CZ` → `POST /api/connect/gocardless/link` → пройти согласие в банке по ссылке → `POST /api/connect/gocardless/sync` |

> Код этих трёх интеграций написан по документации и проходит проверку типов, но **не запускался против живых сервисов**: при разработке ключей не было. Перед демо проверьте их со своими ключами. Если что-то не так, приложение работает в демо-режиме без них.

## 6. Если что-то пошло не так

| Симптом | Решение |
|---|---|
| «Starting Halo… Waiting for the API» | Сервер ещё деплоит контракты (до 20 с) или не запущен `npm run dev` |
| `EADDRINUSE` / порт занят | Закройте старый процесс на 8545, 8787 или 5173 |
| Странное состояние после экспериментов | **Demo lab → Reset the world** или `POST /api/demo/reset` |
| Перезапустили только `chain` | Перезапустите весь `npm run dev`: при старте сервер видит пустой блокчейн и заново деплоит контракты |
| Автотест упал на таймингах | Запустите ещё раз; убедитесь, что во время теста в UI никто не нажимает кнопки |
